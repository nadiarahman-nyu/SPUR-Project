A quick user guide

How to use the prototype

Use the dashboard to explore a simple, transparent demand-planning scenario. It is a learning prototype—not a live data connection, validated AI model, or automated purchasing system.

Start safely: choose CSV data you are authorized to use. The file is read in your browser and is not uploaded by this static page. Start with the fictional sample if you want to explore without company data.

Explore the sample or enter a company

The dashboard opens with fictional example products. Change the brand name, ticker/CIK, forecast-period label, and optional reported revenue/inventory if you have a filing. Use the source filing URL to retain the link you transcribed the figures from.

Company-level annual revenue and inventory provide context; they do not supply item-level sales history. Keep currencies and reporting units clear in your own notes.

Prepare a product CSV

Each row should describe a product using a consistent time period and units. Required columns:

ColumnMeaningExample
productProduct name or identifierEveryday tee
inventoryCurrent available stock, in units240
units_soldRecent units sold during the forecast period length180

Optional columns: category, previous_units_sold, search_change_pct, social_change_pct, material_cost_change_pct, emissions_kg_per_unit, lead_time_days, and source_url. Save as CSV with a header row. Blank optional trend fields fall back to the default signal values on the dashboard.

Add comparable interest and cost signals

Use Google Trends, TikTok Creative Center, or other sources to research signals manually. Enter percentage changes for comparable terms, regions, and time windows (for example, the last 28 days versus the previous 28 days). Add query/source URLs when available. Don’t treat raw search indices or social views as sales quantities.

The page does not retrieve or verify those sites. Use each source’s terms and permitted access methods; don't scrape sites in ways they prohibit.

Upload data and run the forecast

Select the CSV and press Run forecast. If no file is selected, the dashboard reruns the current displayed dataset using the currently entered default interest values. Press Load sample to restore the fictional products and default inputs.

Read the forecast as a rough planning signal

The baseline uses recent sales and clipped growth from a prior sales period plus search/social changes. Current stock is compared with forecast demand and a small planning buffer. The uncertainty band is a fixed illustration, not a statistically calibrated confidence interval.

trend = clamp((recent sales − previous sales) / previous sales, −50%, +50%)
estimated growth = clamp(25% × trend + 20% × search change + 10% × social change, −50%, +50%)
forecast = recent sales × (1 + estimated growth)

Signal fields should be entered as percentage changes (for example, 10 for +10%, not 0.10). Demand units correspond to the same period represented by your recent sales; editing the period label does not change the calculation.

Review sustainable actions—not automatic instructions

  • Pause / reduce orders: stock materially exceeds forecast plus the prototype’s 5% buffer. Check transfers, resale, or repair before producing more.
  • Replenish cautiously: forecast is above stock. Confirm demand and check other locations before ordering; consider supplier lead times.
  • Hold & review: the gap is small enough to recheck sell-through before committing.

The stock-emissions metric multiplies estimated surplus units by an optional per-unit emissions factor. It is an exposure estimate—not measured emissions, waste prevented, or emissions avoided.

Know what the price indicator does not do

The “Price / cost watch” combines entered material-cost changes with interest signals to flag directional pressure. It does not forecast retail prices, recommend a markdown, or model margins.

Validate before making real decisions

Compare forecasts with later actual sales; track units actually produced, transferred, returned, resold, donated, recycled, or discarded; and document emissions-factor sources. Include supplier capacity, lead times, worker safety, fair pay, and overtime constraints. Never use a forecast to justify unsafe or unfair working conditions.
